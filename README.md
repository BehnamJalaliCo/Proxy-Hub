# Proxy-Hub

> **وضعیت (۲۰۲۶-۱۱-۰۱):** فقط طراحی. **هنوز هیچ کدی نوشته نشده و هیچ سروری ساخته نشده است.**
> این ریپو یادداشت کامل گفت‌وگوی مالک و Claude است، تا بعداً (مثلاً سه ماه بعد) بدون یادآوری چیزی، کار از همین‌جا شروع شود.

## در یک جمله
یک **پنل مرکزی تمام‌خودکار** که فقط با **یک توکن API هتزنر** و **یک توکن ربات تلگرام** کار میکند:
- خودش سرورهای پروکسی و VPN را میسازد، سالم نگه میدارد، عوض میکند و حذف میکند.
- خودش هر روز کانفیگ تازه‌ی **رایگان** در **کانال تلگرام** پست میکند و پست‌های تمام‌شده را علامت میزند (هرگز پاک نمیکند).
- همه‌ی این‌ها برای یک هدف است: **جذب عضو برای کانال سیگنال مالک و فضای تبلیغاتی.** سیستم میسنجد هر عضو تازه چقدر خرج داشته است.

مالک **هیچ کار دستی** در اداره‌ی روزانه ندارد. همه‌چیز، از جمله سلامت، با کد کنترل میشود.

## کجا شروع میشود و کجا تمام میشود؟
- **شروع (روز اول):** پیش‌نیازهای مالک در [`docs/08_ROADMAP.md`](docs/08_ROADMAP.md) بخش «فاز ۰». بدون آن‌ها هیچ کدی نوشته نمیشود. مهم‌ترینشان: **project جدا در هتزنر و توکن همان project.**
- **پایان (حالت نهایی):** پنل روی یک سرور کوچک خودش کار میکند. nodeها خودکار ساخته و عوض میشوند. کانال هر روز پر میشود. داشبورد «عضو تازه‌ی کانال سیگنال در روز» و «هزینه‌ی هر عضو» را نشان میدهد. مالک فقط هدف‌ها و سقف بودجه را تعیین میکند.

## سه قانون که هرگز شکسته نمیشود
1. **توکن هتزنر فقط مال project جدای همین سیستم است.** این سیستم سرور میسازد و حذف میکند؛ نباید حتی ببیند سرورهای اصلی مالک (CoinePro-Hub و شرکت‌ها) وجود دارند.
2. **پست‌های کانال هرگز پاک نمیشوند.** فقط ویرایش میشوند تا وضعیت «تمام شد / پر شد / از دسترس خارج شد» بگیرند.
3. **هیچ لاگی از IP یا ترافیک کاربر نگه داشته نمیشود.** فقط آمار کلی.
