# پرامپت ۱۴: node آزمایشی در آمریکا (Ashburn)، و اسپانسر با اصلاح PR ۱۲

> مالک این را میچسباند: «`git pull` بزن (روی `main`)، بعد فایل `ops/prompts/P14.md` را بخوان و دقیق اجرا کن.»

قاعده‌های `ops/prompts/README.md` برقرار است: فارسی و **کوتاه** با مالک. هیچ رمز، کلید، لینک یا uuid در گزارش نیاید.

**چرا:** گزارش P13 نشان داد بازه‌ی IP فالکنشتاین (fsn1) روی همراه اول دست‌دادن TLS را رد میکند. ولی سرور خود مالک در Ashburn درست کار میکند.

فرمان‌ها:
- `C="sudo docker compose -p proxyhub exec -T api python -m proxyhub.nodes"`
- `Q() { sudo docker compose -p proxyhub exec -T postgres psql -U proxyhub -d proxyhub -At -c "$1"; }`

1. **پیش‌شرط:**
   - `deploy_status.sh` باید `RESULT: up to date` با commit `0eae8b5` یا تازه‌تر بدهد.
2. **نوع سرورهای آمریکا:**
   - `Q "SELECT location, server_type, round(price_monthly_net,2), included_traffic_bytes/1e12 AS tb, available FROM hetzner_offers WHERE location IN ('ash','hil') AND NOT deprecated ORDER BY price_monthly_net LIMIT 8"`
   - ارزان‌ترین نوعی که `available` آن `t` است و دست‌کم ۲ هسته دارد را `<TYPE>` بنام.
3. **از مالک بخواه** (داشبورد ← «تنظیمات»):
   - «مکان‌ها را فقط `ash` بگذارید، و `<TYPE>` را هم به نوع‌های مجاز اضافه کنید. ذخیره کنید.» سقف‌ها و حالت خشک را عوض نکند.
   - «در صفحه‌ی nodeها node آزمایشی فعلی (fsn1) را بازنشسته کنید.» صبر کن: `$C wait <ID قبلی> deleted --timeout 600`.
   - «"ساخت node آزمایشی" را بزنید.» سپس `$C wait <ID> ready --timeout 1500`.
   - `$C list` باید برای node تازه `location` برابر `ash` نشان دهد.
4. **سنجش از ایران پیش از آزمون مالک:**
   - با Globalping یک سنجش **http** بزن (نه ping)، روی `https://<name>/` (نام `t<hex>.ipoxxo.online` از صفحه‌ی Reality)، با `locations` برابر `[{"asn":197207,"limit":2},{"country":"IR","limit":6}]`.
   - هر کدِ HTTP (مثلاً 404) یعنی دست‌دادن TLS از آن شبکه درست است. timeout یعنی بسته است.
   - همین را برای سرور خود مالک (`5.161.145.63`) هم بزن، به‌عنوان کنترل.
5. **از مالک بخواه** (گوشی، **VPN خاموش**):
   - «لینک تازه‌ی صفحه‌ی Reality را در V2BOX وارد کنید و fast.com را بزنید. عدد؟»
   - «لینک تازه‌ی MTProto را در تلگرام وصل کنید (Use Proxy روشن). یک ویدیو باز کنید. دانلود شد؟»
   - «اپراتور؟ وای‌فای یا اینترنت گوشی؟»
6. **اسپانسر** (اصلاح PR ۱۲ مستقر است):
   - از مالک بخواه در صفحه‌ی «اسپانسر» **یک بار** «ثبت دوباره» را بزند.
   - تا ۱۰ دقیقه: `Q "SELECT action FROM actions_log WHERE action LIKE 'sponsor%' ORDER BY id DESC LIMIT 15"` باید `promotion_set` نشان دهد.
   - اگر باز گیر کرد، `stuck_reason` و شکل برچسب دکمه‌ها را گزارش کن. برای برچسب، hex را با `<hex N>` جایگزین کن (N تعداد حروف است).
7. **گزارش** در یک بلوک کوتاه: نتیجه‌ی سنجش http از هر شبکه‌ی ایران، عدد سرعت، دانلود MTProto، و اسپانسر.

**نکن:**
- خودت تنظیمات را عوض نکن؛ فقط مالک، از داشبورد.
- بیش از یک node نساز.
- `git push` نکن.
