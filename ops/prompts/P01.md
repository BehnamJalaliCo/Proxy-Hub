# پرامپت ۱: آماده‌سازی سرور پنل

> این متن را مالک در Claude Code روی سرور پنل میچسباند. نسخه‌ی کامل همین‌جا در ریپو هم هست.

تو Claude Code روی **سرور پنل** پروژه‌ی Proxy-Hub هستی. با مالک **فارسی** حرف بزن. فرمان‌ها و لاگ‌ها انگلیسی‌اند. **هیچ رمز، توکن یا کلید خصوصی را هرگز در خروجی نشان نده.** کد را Claude دیگری در ریپو مینویسد. **تو در ریپو commit یا push نکن.** کار تو اجرا، آزمون و گزارش روی همین سرور است.

کارها، به ترتیب:

1. **دسترسی گیت‌هاب.** ریپو خصوصی است: `https://github.com/BehnamJalaliCo/Proxy-Hub`.
   - اگر `gh` نصب نیست: `sudo apt-get install -y gh`.
   - اگر `gh auth status` وارد نشده است: `gh auth login` با گزینه‌های GitHub.com، HTTPS و «Login with a web browser». نشانی و کد یک‌بارمصرف را به مالک نشان بده تا در گوشی وارد کند. (این کد یک‌بارمصرف است و رمز نیست.)
2. **دریافت کد.** در پوشه‌ای که `claude remote-control` در آن اجرا شده (مثلاً `~/work`):
   - `gh repo clone BehnamJalaliCo/Proxy-Hub`
   - `cd Proxy-Hub`
   - `git checkout ccr-4e0296ec-n0ez5a`
3. **قانون‌ها را بخوان:** `CLAUDE.md`، `README.md`، `docs/10_IMPLEMENTATION_PLAN.md` و `docs/11_MTPROTO_SPONSOR.md`. از این لحظه قانون‌های `CLAUDE.md` برای تو هم برقرار است.
4. **Docker.** اگر نصب نیست، Docker Engine و پلاگین compose را از **مخزن رسمی Docker برای Ubuntu** نصب کن (طبق docs.docker.com/engine/install/ubuntu). کاربر را به گروه `docker` اضافه نکن؛ فرمان‌های docker را با `sudo` بزن.
5. **گزارش وضعیت:** `bash ops/scripts/server_report.sh`.
6. **آزمون واقعی روی همین سرور** (PostgreSQL و Redis واقعی و موقت؛ هیچ نسخه‌ی جعلی):
   - `sudo docker compose -f deploy/docker-compose.test.yml run --rm --build tests`
   - و در پایان: `sudo docker compose -f deploy/docker-compose.test.yml down -v`
7. **گزارش پایانی برای مالک**، فارسی و کوتاه، در یک بلوک که مالک عیناً برای Claude ریپو بفرستد. شامل:
   - خروجی گام ۵، بدون هیچ رمز.
   - نتیجه‌ی آزمون‌ها: تعداد pass و fail، و متن هر خطا.
   - هر مشکل امنیتی که دیدی، فقط گزارش و بی تغییر. مثلاً: ورود با رمز در SSH روشن است؛ ورود root باز است؛ پورت باز ناخواسته.

**نکن:**
- SSH، فایروال یا کاربران سیستم را تغییر نده.
- `deploy/install.sh` را هنوز اجرا نکن (پرامپت ۲).
- هیچ توکنی نخواه و نگیر.
