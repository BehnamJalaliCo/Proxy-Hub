# پرامپت ۱۵: پژوهش خودکار. کدام مکان و کدام کانفیگ از ایران واقعاً کار میکند؟

> مالک این را میچسباند: «`git pull` بزن (روی `main`)، بعد فایل `ops/prompts/P15.md` را بخوان و تا رسیدن به نتیجه، خودت اجرا کن.» این پرامپت جای P14 را میگیرد.

قاعده‌های `ops/prompts/README.md` برقرار است:
- فارسی و **کوتاه** با مالک.
- هیچ رمز، کلید، لینک یا uuid در گزارش نیاید.
- commit یا push نکن.

**هدف:** با داده، نه حدس، پیدا کن چرا کانفیگ ما از ایران (به‌ویژه همراه اول) کار نمیکند ولی کانفیگ خود مالک کار میکند. بعد بهترین مکان را پیشنهاد بده. مالک نمیخواهد هر روز آزمون بگیرد. پس **همه‌ی سنجش‌ها را خودت انجام بده** و فقط در پایان یک بار از مالک بخواه یک لینک را امتحان کند.

## اجازه‌های این پرامپت
- با CLI پنل **node آزمایشی بساز و بازنشسته کن**، **هر بار فقط یکی**:
  - `$C test-node --location <loc>`
  - `$C retire <ID>`
  - `$C wait <ID> ready|deleted`
- همه‌ی قفل‌های پنل برقرار است: سقف بودجه، سقف node، و یک node آزمایشی در هر زمان. هیچ قفلی را دور نزن.
- با Globalping (`https://api.globalping.io/v1/measurements`) و check-host از ایران بسنج.
- تنظیمات را خودت عوض نکن. اگر لازم شد، فقط از مالک بخواه.

فرمان‌ها:
- `C="sudo docker compose -p proxyhub exec -T api python -m proxyhub.nodes"`
- `Q() { sudo docker compose -p proxyhub exec -T postgres psql -U proxyhub -d proxyhub -At -c "$1"; }`

## ۱. آماده‌سازی (فقط یک بار از مالک)
1. نوع سرورهای هر مکان را بخوان:
   `Q "SELECT location, server_type, round(price_monthly_net,2), included_traffic_bytes/1e12 AS tb FROM hetzner_offers WHERE available AND NOT deprecated ORDER BY location, price_monthly_net"`
2. **یک پیام** به مالک بده: «در "تنظیمات"، مکان‌ها را `fsn1, nbg1, hel1, ash, hil` و نوع‌های مجاز را `<فهرست ارزان‌ترین نوع ۲هسته‌ای هر مکان>` بگذارید. کلید توقف خاموش بماند. ذخیره کنید و بگویید "زدم".»
3. node آزمایشی فعلی را با `$C retire` بازنشسته کن و صبر کن تا حذف شود.

## ۲. حلقه‌ی سنجش، برای هر مکان به‌ترتیب `fsn1, nbg1, hel1, ash, hil`
1. `$C test-node --location <loc>` و بعد `$C wait <ID> ready --timeout 1500`.
2. صبر کن تا صفحه‌ی Reality کانفیگ `ws_tls` فعال روی نام `t<hex>.ipoxxo.online` نشان دهد. از سرور پنل بسنج که `openssl s_client` روی 443 و 8443 نتیجه‌ی `Verify return code: 0` بدهد.
3. **سنجش TLS واقعی از ایران** با Globalping، نه ping یا TCP، چون همراه اول به TCP جواب جعلی میدهد:
   - درخواست:
     ```
     {"type":"http","target":"<name>","measurementOptions":{"protocol":"HTTPS","port":443,"request":{"method":"HEAD","path":"/"}},"locations":[{"asn":197207,"limit":3},{"asn":44244,"limit":2},{"asn":58224,"limit":2},{"asn":31549,"limit":1},{"asn":57218,"limit":1},{"country":"IR","limit":4}]}
     ```
   - همین را برای درگاه 8443 هم بزن (MTProto).
   - **کنترل‌ها در همان دور:** سرور سالم مالک (`ir.beyra-ai.com`) و `panel.beyra-ai.com`.
   - هر کد HTTP یعنی TLS سالم است. timeout یا خطای TLS یعنی بسته است. timingهای `tls` و `total` را هم نگه دار.
   - نکته: هر probe یک «test» Globalping است و سقف ساعتی دارد. اگر به سقف خوردی، صبر کن.
4. `$C retire <ID>` و صبر تا حذف. سپس مکان بعدی.
5. هر node حداکثر ۴۵ دقیقه زنده بماند.

## ۳. نتیجه
1. یک جدول بساز: **مکان × شبکه (همراه اول، ایرانسل، مخابرات، شاتل، رایتل، بقیه)**. در هر خانه بنویس TLS درست شد یا نه، و زمان. یک سطر هم برای سرور مالک و پنل بیاور.
2. **حکم:** اگر سرور مالک از همان شبکه‌ای درست است که node ما از آن بسته است، و node ما در مکانی دیگر درست است، مشکل مکان است. اگر node ما در **همه‌ی** مکان‌ها بسته است و سرور مالک باز، مشکل از ساخت کانفیگ ماست. آن وقت جزئیات کامل دست‌دادن TLS را بیاور:
   - `openssl s_client -connect <ip>:443 -servername <name> -tls1_3 -alpn http/1.1 -showcerts` (فقط زنجیره، بی کلید)؛
   - همین برای سرور مالک (نسخه‌ی TLS، cipher، ALPN، صادرکننده، طول زنجیره).
   فرق‌ها را فهرست کن.
3. در مکان برنده یک node آزمایشی بساز و نگه دار. **فقط یک بار** از مالک بخواه: «لینک تازه‌ی Reality را در V2BOX با اینترنت گوشی و بی VPN بزنید و fast.com را باز کنید. عدد؟»
4. **اسپانسر:** از مالک بخواه یک بار «ثبت دوباره» را بزند. تا ۱۰ دقیقه `promotion_set` در `actions_log` بیاید. اگر نیامد، `stuck_reason` و شکل برچسب دکمه را بیاور (hex را با `<hex N>` جایگزین کن).
5. **گزارش پایانی** برای Claude ریپو در یک بلوک: جدول، حکم، عدد سرعت، اسپانسر، و هزینه‌ی کل nodeهای آزمایشی.

**نکن:**
- بیش از یک node در هر زمان نساز.
- تنظیمات را خودت عوض نکن.
- `git push` نکن.
- هیچ لینک یا uuid در گزارش نیاور.
