# پرامپت ۳: سخت‌سازی سرور پنل (تصمیم‌های مالک ۲۰۲۶-۱۱-۰۳)

> مالک فقط این را میچسباند: «`git pull` بزن، بعد فایل `ops/prompts/P03.md` را بخوان و دقیق اجرا کن.» این پرامپت پس از سبز شدن پرامپت ۲ اجرا میشود.

همان قانون‌ها برقرار است: با مالک فارسی حرف بزن؛ هیچ رمزی را نشان نده؛ در ریپو commit یا push نکن.

**تصمیم مالک (D28):** SSH روی پورت فعلی و **با ورود رمزی میماند**. فقط **fail2ban** و **فایروال خود سرور (ufw)** اضافه میشود. تنظیم SSH را تغییر نده.

1. **پورت واقعی SSH را بخوان:** `sudo sshd -T | grep -i '^port '`. انتظار: `1367`. از این به بعد هر جا `SSH_PORT` آمده، همین عدد است.
2. **fail2ban:**
   - `sudo apt-get install -y fail2ban`
   - فایل `/etc/fail2ban/jail.d/proxyhub-sshd.local`، دقیقاً با این محتوا (به‌جای `SSH_PORT` عدد گام ۱):
     ```
     [sshd]
     enabled = true
     port = SSH_PORT
     backend = systemd
     maxretry = 5
     findtime = 10m
     bantime = 1h
     bantime.increment = true
     bantime.maxtime = 1w
     ```
   - `sudo systemctl enable --now fail2ban && sudo systemctl restart fail2ban`
   - سنجش: `sudo fail2ban-client status sshd` باید jail فعال را نشان دهد.
3. **ufw**. **ترتیب مهم است: اول اجازه، بعد روشن کردن،** وگرنه SSH قطع میشود:
   - `sudo ufw default deny incoming`
   - `sudo ufw default allow outgoing`
   - `sudo ufw allow SSH_PORT/tcp`
   - `sudo ufw allow 80/tcp`
   - `sudo ufw allow 443/tcp`
   - دوباره بسنج که قانون `SSH_PORT/tcp` در `sudo ufw show added` هست. **فقط بعد از آن:** `sudo ufw --force enable`
   - سنجش: `sudo ufw status verbose`.
   - **نکته:** پورت‌هایی که Docker منتشر میکند از ufw رد میشوند. در این پروژه فقط `127.0.0.1:8000` (داخلی) و بعداً 80 و 443 (Caddy) منتشر میشوند، که درست است.
4. **پنل هنوز سالم است؟** `curl -s http://127.0.0.1:8000/healthz` باید `"status":"ok"` بدهد.
5. **گزارش پایانی** فارسی برای مالک، در یک بلوک برای Claude ریپو: خروجی `fail2ban-client status sshd` (بی IP؛ اگر IP مسدودشده‌ای هست، فقط تعدادش را بگو)، خروجی `ufw status verbose`، و نتیجه‌ی `/healthz`.

**نکن:** `sshd_config` را تغییر نده (رمز میماند، طبق تصمیم مالک). فایروال ابری هتزنر را تغییر نده.
