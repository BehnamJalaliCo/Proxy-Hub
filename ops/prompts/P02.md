# پرامپت ۲: نصب پنل و استقرار خودکار (GitOps)

> مالک فقط این را میچسباند: «فایل `ops/prompts/P02.md` را بخوان و دقیق اجرا کن.» پیش از آن، `git pull` بزن.

همان قانون‌های پرامپت ۱ برقرار است: با مالک فارسی حرف بزن؛ هیچ رمزی را نشان نده؛ در ریپو commit یا push نکن.

1. `git pull`. شاخه باید `ccr-4e0296ec-n0ez5a` باشد.
2. `sudo bash deploy/install.sh ccr-4e0296ec-n0ez5a`
   - اگر با کد `2` تمام شد، یعنی **deploy key** لازم است. کلید **عمومی** چاپ‌شده (فقط خط `ssh-ed25519 …`؛ عمومی است و رمز نیست) و این نشانی را به مالک بده: `https://github.com/BehnamJalaliCo/Proxy-Hub/settings/keys/new`. به مالک بگو: عنوان `proxy-hub-panel`، کلید را بچسباند، **Allow write access خاموش**، و Add key. پس از تأیید مالک، همان فرمان را دوباره اجرا کن.
   - بار اول ساخت imageها چند دقیقه طول میکشد.
3. **سنجش:**
   - `curl -s http://127.0.0.1:8000/healthz`: باید `"status":"ok"` باشد و `db` و `redis` هر دو `true`.
   - `sudo docker compose -p proxyhub ps`: همه‌ی سرویس‌ها بالا و سالم.
   - `systemctl status proxyhub-deployer.timer --no-pager`: فعال.
   - `sudo ls -l /etc/proxy-hub /etc/proxy-hub/secrets`: پوشه‌ها `drwx------ root`. **محتوای فایل‌ها را نخوان و چاپ نکن.**
   - پورت 8000 باید فقط روی `127.0.0.1` باشد: `ss -tlnp | grep 8000`.
4. **سنجش اصلاح‌های گزارش پرامپت ۱:**
   - رمز Redis نباید در فهرست پروسه‌ها باشد: `ps aux | grep -c "[r]equirepass"` باید `0` بدهد. **خود خروجی `ps` را در گزارش نگذار.**
   - همه‌ی imageها digest دارند: `sudo docker compose -p proxyhub images`.
   - کلید میزبان گیت‌هاب از پیش ثبت شده است: `sudo cat /etc/proxy-hub/known_hosts | wc -l`.
   - آزمون کامل دوباره: `sudo docker compose -f deploy/docker-compose.test.yml run --rm --build tests`. این بار ruff و mypy هم اجرا میشوند و هشدار cache نباید بیاید. در پایان: `sudo docker compose -f deploy/docker-compose.test.yml down -v`.
5. **آزمون آشوب سبک (واقعی):**
   1. `sudo docker compose -p proxyhub stop worker`
   2. حداکثر ۱۲۰ ثانیه صبر کن. `/healthz` باید `503` بدهد، با `"worker":"stale"`.
   3. `sudo docker compose -p proxyhub start worker`
   4. پس از حداکثر ۳۰ ثانیه باید دوباره `200` بدهد.
6. **آزمون restart کل سرویس‌ها:** `sudo docker compose -p proxyhub restart`، سپس `/healthz` تا ۹۰ ثانیه سبز شود.
7. **گزارش پایانی برای مالک**، فارسی، در یک بلوک برای فرستادن به Claude ریپو:
   - نتیجه‌ی هر گام.
   - commit مستقرشده: `cat /var/lib/proxy-hub/deployed_commit`.
   - خروجی `/healthz`.
   - هر خطا با ۳۰ خط آخر لاگ مربوط: `sudo journalctl -u proxyhub-deployer --no-pager -n 30` یا `sudo docker compose -p proxyhub logs --tail 30 api worker`. پیش از گذاشتن لاگ در گزارش، مطمئن شو هیچ رمزی در آن نیست.

**نکن:** دامنه، Caddy، فایروال و SSH را تغییر نده. آن‌ها پرامپت ۳ است.
