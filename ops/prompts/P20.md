# پرامپت ۲۰: اسپانسر پس از پاک شدن همه‌چیز در ‎@MTProxybot‎، کپی جدای هر کانفیگ، SNI بی اپل

> مالک این را میچسباند: «`git pull` بزن (روی `main`)، بعد فایل `ops/prompts/P20.md` را بخوان و تا رسیدن به نتیجه، خودت اجرا کن.»

قاعده‌های `ops/prompts/README.md` برقرار است:
- فارسی و **کوتاه** با مالک.
- هیچ رمز، کلید، لینک، uuid یا tag کامل در گزارش نیاید.
- commit یا push نکن.

فرمان‌ها:
- `Q() { sudo docker compose -p proxyhub exec -T postgres psql -U proxyhub -d proxyhub -At -c "$1"; }`
- `C2="sudo docker compose -p proxyhub exec -T api python -m proxyhub.sponsor"`

**چه عوض شد (PR ۲۲، پس از P19):**
- **اسپانسر:**
  - وقتی ‎/myproxies‎ بگوید «You didn't create any proxy yet»، ثبت قدیمی برای همیشه بازنشسته میشود (`removed_in_bot`).
  - tag کهنه از node برداشته میشود.
  - گذر بعدی پروکسی را با ‎/newproxy‎ دوباره ثبت میکند و ‎@ipoxxo‎ را اسپانسرش میکند.
  - فهرست خالی ‎@MTProxybot‎ حالا «کامل و خالی» است، نه توقف.
- **پست:**
  - هر کانفیگ ریلیتی (TCP و XHTTP) نقل‌قول جمع‌شونده‌ی خودش را دارد. یک لمس یعنی یک کانفیگ.
  - پیامی که در کانال پاک شده باشد، یک بار «پاک‌شده» (`gone_at`) علامت میخورد. دیگر ویرایش و هشدار ندارد. مهاجرت `0024_post_gone` همین را اضافه میکند.
  - اولین نویسه‌ی پست ایموجی معمولی است، نه متحرک، چون iOS ایموجی متحرکِ اولِ پیام را نشان نمیدهد.
- **SNI:**
  - نامی که Xray درباره‌اش هشدار میدهد هرگز هدف Reality نمیشود: apple، icloud و microsoft در نام، یا پسوند `.ru`، `.ir` و `.cn`.
  - کلید node آزمایشی که هنوز روی `www.apple.com` است، فوراً به نام امن میرود. کانفیگ‌های اپلی آن «سوخته» میشوند.

0. **پیش‌شرط:**
   - `deploy_status.sh` باید `RESULT: up to date` بدهد.
   - `Q "SELECT version_num FROM alembic_version"` باید `0024_post_gone` بدهد.
   - شمار خطای worker باید ۰ باشد.
1. **SNI** (تا ۵ دقیقه پس از استقرار):
   - پیش از هر چیز این‌ها را بیاور. در گزارش فقط نام میزبان‌ها را بنویس، نه uuid یا کلید:
     - `Q "SELECT value->>'target_host', value->>'target_mode' FROM settings WHERE key='reality'"`؛
     - `Q "SELECT value FROM settings WHERE key='targets'"`.
   - `Q "SELECT action, reasons FROM actions_log WHERE action IN ('target_auto_switched','reality_target_switched') ORDER BY id DESC LIMIT 5"`. انتظار: یک `reality_target_switched` با `risky_sni`.
   - نام هدف کلیدِ node آزمایشی دیگر نباید `www.apple.com` باشد. نام ستون را از جدول کلیدهای Reality پیدا کن و فقط نام میزبان را گزارش کن.
   - یکی دو دقیقه بعد باید کانفیگ تازه‌ای ساخته شود. `sni` آن را از روی لینک گزارش کن، **فقط مقدار sni**.
2. **اسپانسر** (مالک، تا ۲۰ دقیقه):
   - مالک در صفحه‌ی «اسپانسر» برای پروکسی فعال **یک بار** «ثبت دوباره» را بزند.
   - سپس این را بسنج:

     `Q "SELECT r.state, r.state_reason, r.sponsor_channel, f.stuck_reason, f.promotion_set_at IS NOT NULL FROM sponsor_flows f LEFT JOIN mtproxy_registrations r ON r.id = f.registration_id ORDER BY f.created_at DESC LIMIT 3"`

     انتظار:
     - ردیف تازه: `registered||ipoxxo||t`؛
     - ردیف قدیمی: `retired|removed_in_bot|…`.
   - ۱۲ خط آخر `Q "SELECT action, target FROM actions_log WHERE action LIKE 'sponsor.%' ORDER BY id DESC LIMIT 12"` را بیاور. انتظار، به ترتیب:
     1. `registration_forgotten`
     2. `tag_cleared`
     3. `proxy_found`
     4. `registered`
     5. `tag_applied`
     6. `promotion_set`
   - اگر جایی ایستاد: `stuck_reason`، `last_step` و `last_bot_text` را بیاور (پوشیده است).
3. **فهرست ‎@MTProxybot‎:**
   - `$C2 inventory`، بعد `$C2 wait --timeout 3600`، بعد `$C2 status`.
   - انتظار: یک ردیف، `live`، `exact: true`.
   - `counts` و `promotion` را گزارش کن. «ok» ممکن است تا یک ساعت پس از تنظیم اسپانسر طول بکشد.
4. **پست** (کانال آزمایشی):
   - `Q "SELECT id, edits, edit_failures, gone_at IS NOT NULL FROM posts ORDER BY id DESC LIMIT 5"`.
   - پست‌های ۴۸ ساعت اخیر باید یک بار ویرایش شده باشند و `edit_failures` صفر باشد.
   - از مالک بخواه روی آیفون ببیند:
     - زیر «🔒 کانفیگ V2Ray» دو نقل‌قول جدا آمده است: TCP و XHTTP؛
     - لمس هر کدام فقط همان یک کانفیگ را کپی میکند و V2Box هر دو را جدا وارد میکند؛
     - ایموجی سرتیتر حالا دیده میشود.
   - اگر تا ۳۰ دقیقه پست تازه‌ای نرفت، همان روش P19 را بکن: یک `try_run_once` با patch فقط برای slot همان اجرا.
5. **آزمون اسپانسر** (مالک، دست‌کم ۱ ساعت پس از `promotion_set`):
   - با حسابی که عضو ‎@ipoxxo‎ نیست، با «پروکسی ۱» از آخرین پست کانال آزمایشی وصل شود.
   - ببیند ‎@ipoxxo‎ با برچسب «Proxy Sponsor» بالای چت‌ها میآید یا نه.
6. **گزارش پایانی** در یک بلوک کوتاه برای Claude ریپو.
