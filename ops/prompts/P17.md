# پرامپت ۱۷: اصلاح‌های P16، بسته‌ی ایموجی کانال، آزمون آپلود

> مالک این را میچسباند: «`git pull` بزن (روی `main`)، بعد فایل `ops/prompts/P17.md` را بخوان و تا رسیدن به نتیجه، خودت اجرا کن.»

قاعده‌های `ops/prompts/README.md` برقرار است:
- فارسی و **کوتاه** با مالک.
- هیچ رمز، کلید، لینک یا uuid در گزارش نیاید.
- commit یا push نکن.

فرمان‌ها:
- `C="sudo docker compose -p proxyhub exec -T api python -m proxyhub.nodes"`
- `Q() { sudo docker compose -p proxyhub exec -T postgres psql -U proxyhub -d proxyhub -At -c "$1"; }`

**چه عوض شد (از گزارش P16):**
- **سنجش TLS فقط روی 443 است.** Telemt فقط دامنه‌ی خودش را جواب میدهد، پس سنجش 8443 با نام node همیشه «بسته» میشد.
- **سنجش زودهنگام:** node تا ۵ دقیقه پس از READY سنجیده نمیشود.
- **مکان‌ها:** nodeها روی همه‌ی مکان‌های نابسته پخش میشوند، نه فقط hel1.
- **سایت هدف:** `github.com` اول فهرست پیش‌فرض است. `www.apple.com` از فهرست بیرون رفت (Xray 26.10.31 خودش درباره‌ی SNI اپل هشدار میدهد).
- **بسته‌ی ایموجی کانال (D43):** ربات یک بار بسته‌ی ایموجی متحرک کانال را میسازد (۲۸ ایموجی، عنوان ‎@ipoxxo‎).
- **سنجش‌های دستی Globalping:** دیگر از IP پنل نزن؛ سهمیه‌ی پنل را میخورد.

1. **پیش‌شرط:**
   - `deploy_status.sh` باید `RESULT: up to date` بدهد.
   - `Q "SELECT version_num FROM alembic_version"` باید `0021_operator_poster` بدهد.
   - شمار خطای worker باید ۰ باشد.
2. **بسته‌ی ایموجی** (تا ۵ دقیقه پس از استقرار):
   - `Q "SELECT value->>'name', jsonb_array_length(value->'alts'), value->>'error' FROM settings WHERE key='posts.own_pack'"` باید `۲۸` ایموجی و خطای خالی نشان دهد.
   - `Q "SELECT action, target FROM actions_log WHERE action LIKE 'posts.own_pack%' ORDER BY id DESC LIMIT 5"` باید `posts.own_pack_created` نشان دهد.
   - اگر خطا داشت، متن `error` را بی توکن گزارش کن. اگر `reason` در صفحه‌ی «محتوا» `no_public_channel` بود، یعنی کانال اصلی در صفحه‌ی تلگرام ثبت نیست یا @ ندارد.
   - از مالک بخواه: در صفحه‌ی «محتوا»، فرستنده را «حساب دوم (Premium)» بگذارد (اگر نیست) و «بررسی حالا» را بزند. کادر «بسته‌ی اختصاصی کانال» باید «در حال استفاده» باشد.
   - پست بعدی کانال آزمایشی باید ایموجی متحرک داشته باشد. از مالک بپرس.
3. **سنجش‌ها** (۳۰ تا ۶۰ دقیقه پس از استقرار):
   - `Q "SELECT kind, port, status, count(*) FROM probe_measurements WHERE at > now()-interval '1 hour' AND kind='https' GROUP BY 1,2,3"`. فقط درگاه 443 باید باشد.
   - `Q "SELECT n.location, s.verdict FROM probe_node_state s JOIN nodes n ON n.id=s.node_id"`. node در hel1 باید `ok` باشد.
4. **سایت هدف:**
   - `Q "SELECT value FROM settings WHERE key='targets'"`.
   - اگر ردیفی هست و `www.apple.com` در آن است، از مالک بخواه در «تنظیمات» ← «سایت‌های هدف» آن را بردارد و `github.com` را اول بگذارد.
   - سپس `Q "SELECT action, target, reasons->'context' FROM actions_log WHERE action IN ('target_auto_switched','target_no_candidate') ORDER BY id DESC LIMIT 5"`.
   - لینک‌های قبلی تا پایان عمرشان همان هدف را نگه میدارند.
5. **XHTTP در داشبورد:**
   - `curl` روی `/api/reality` (با نشست مالک یا از درون کانتینر api). برای هر کانفیگ فعال، `xhttp.url` باید پر باشد.
   - از مالک بخواه صفحه‌ی Reality را باز کند. هر کانفیگ نشان «+ XHTTP» دارد و دو ردیف «TCP» و «XHTTP»، هر کدام با دکمه‌ی کپی.
   - اگر نمیبیند، یک عکس از صفحه بگیرد.
6. **آزمون آپلود از مالک** (گوشی، **VPN خاموش**، اینترنت گوشی). یک بار:
   - لینک **XHTTP** در V2BOX ← سایت `speed.cloudflare.com`: دانلود و آپلود؟
   - لینک **TCP** ← همان سایت: دانلود و آپلود؟
   - **MTProto:** یک ویدیوی حدود ۳۰ مگ را به Saved Messages بفرستد. فرستاده شد؟ چقدر طول کشید؟
   - اپراتور؟
   - **چرا:** طبق پژوهش (۳x-ui، Marzban، PasarGuard، مخزن Xray)، کانفیگ ما محدودیت آپلود ندارد. سرور پنل از همین node آپلود ~15MB/s گرفت. احتمال اصلی محدود کردن آپلود از سوی همراه اول است، روی جفت IP و SNI. این آزمون مشخص میکند مشکل فقط از TCP+Vision است یا از IP/SNI.
7. **مکان‌ها:** `Q "SELECT location, network, state FROM probe_location_reach ORDER BY 1,2"` را گزارش کن. سقف node و حالت خشک با مالک است؛ خودت عوض نکن.
8. **گزارش پایانی** در یک بلوک کوتاه برای Claude ریپو:
   - نتیجه‌ی هر گام؛
   - شش عدد سرعت (دانلود و آپلود XHTTP و TCP)؛
   - نتیجه‌ی آپلود MTProto؛
   - اپراتور.

**نکن:**
- تنظیمات را خودت عوض نکن.
- بیش از یک node نساز.
- `git push` نکن.
- **پست کانال را حذف نکن** (قانون ۶)، مگر مالک همان لحظه صریحاً بخواهد.
