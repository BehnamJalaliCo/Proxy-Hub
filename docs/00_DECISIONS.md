## شرط‌های Claude که مالک باید بپذیرد
- **project جدا در هتزنر و توکن فقط از همان project.**
  - **چرا:** سیستمی که خودکار سرور حذف میکند، اگر توکن project فعلی را داشته باشد، میتواند به سرورهای اصلی مالک برسد.
  - **حساب جدا بهتر است:** abuse روی پروکسی عمومی ممکن است کل **حساب** هتزنر را قفل کند. با project جدا، توکن ایمن است، ولی خطر قفل شدن حساب هنوز هست. این تصمیم با مالک است (O1).
- **هیچ لاگ IP یا ترافیک کاربر.**
  - **چرا:** کاربران در ایران از فیلترشکن استفاده میکنند. لاگ نشت‌کرده میتواند برای خودشان خطر بسازد.
